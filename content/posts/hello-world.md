## 为什么搭建这个主页

一直想有一个安静、克制、不被算法和信息流打扰的角落，用来沉淀通过阅读提炼出来的想法。

这个站点参考了 [Lil'Log](https://lilianweng.github.io/) 的极简阅读风格，完全基于**纯静态 HTML/CSS/JS + Markdown** 搭建，零构建工具依赖，推送到 GitHub Pages 即可上线。

## 这里会写什么

本站聚焦于当代年轻人普遍面临的两个核心问题——**经济问题**与**心理问题**。

原始的读书笔记都会保留在本地，这里只发布从阅读中进一步浓缩出来的**纯理论思考与概念梳理**，涉及学习、就业、理财与税收、情绪与自我认知等方向。关于站点的更多说明，可以查看 [FAQ & 说明](faq.html)。

> 写作不是思考的终点，而是把模糊想法整理清楚的最好方式。

## 排版功能一览

| 功能 | 说明 |
| --- | --- |
| 自动目录（TOC） | 自动提取正文中的二级和三级标题，支持折叠 |
| 亮 / 暗色模式 | 点击顶部图标或按 `Alt + T` 即可切换 |
| 纯前端搜索 | 支持按标题、摘要与标签即时检索 |
