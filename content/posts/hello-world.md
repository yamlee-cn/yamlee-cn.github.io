## 为什么搭建这个主页

一直想有一个安静、克制、不被算法和信息流打扰的角落，用来沉淀日常学到的东西。

这个站点参考了 [Lil'Log](https://lilianweng.github.io/) 的极简阅读风格，完全基于**纯静态 HTML/CSS/JS + Markdown** 搭建，零构建工具依赖，推送到 GitHub Pages 即可上线。

## 这里会写什么

接下来主要分为两个板块持续更新：

1. **分享**：工作、技术、效率工具与日常思考的总结。
2. **读书笔记**：从自己的阅读记录中筛选出适合公开分享的书摘、框架拆解与读后感（私人向或未整理的笔记依然保留在本地）。

> 写作不是思考的终点，而是把模糊想法整理清楚的最好方式。

## 排版功能一览

本站点内置了轻量级 Markdown 渲染器，支持常见写作语法：

### 列表与表格

| 功能 | 说明 |
| --- | --- |
| 自动目录（TOC） | 自动提取正文中的二级和三级标题，支持折叠 |
| 亮 / 暗色模式 | 点击顶部图标或按 `Alt + T` 即可切换 |
| 纯前端搜索 | 支持按标题、书名、作者、标签即时检索 |

### 代码块示例

```bash
# 本地启动静态预览服务
python3 -m http.server 8000
```
